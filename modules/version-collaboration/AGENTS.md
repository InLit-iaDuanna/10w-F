# Version and Collaboration Module Rules

## Ownership

This module owns Git/LFS inspection, review metadata, four-layer review diffs,
comment anchors, assignments, decisions, approvals, binary asset locks, activity,
release evidence links, and approval-gated rollback proposals.

It does not own project files, another module's entities, release execution,
rendering, playtest execution, or the Forge shell. Cross-module references are
stable IDs and documented public payloads only.

## Invariants

- Git remains the source version foundation; this module never invents another VCS.
- Approval, decision, assignment, comment, lock, and activity records are append-only.
- Comments always retain a version and a typed target anchor.
- Binary conflicts use locks, branches, and review; they are never auto-merged.
- A rollback is a typed proposal. Execution requires a matching immutable approval
  and creates new Git history instead of resetting existing history.
- Raw Git output is adapter-private. User-facing states are structured and Chinese.
- Every result has an explicit `live`, `cached`, `mock`, `planned`, or `blocked` mode.

## Commands

From this module directory:

```text
PYTHONPATH=backend/src python3 -m unittest discover -s backend/tests -v
npm --prefix frontend test
```

## Generated files

`contracts/openapi.json` and `frontend/src/generated/api-types.ts` are generated by
`backend/scripts/generate_contracts.py`; do not hand-edit them.

## Integration contracts

- Git access uses `GitAdapter`; no route or editor runs shell commands.
- Render, build, playtest, issue, asset, and scene references are stable IDs.
- `review.*@1` events use the documented event envelope.
- The composition root supplies authenticated actors, project roots, and an event
  publisher when those core services become available.

## Acceptance tests

Keep success and failure coverage for Git offline/dirty/conflict, LFS metadata,
each diff layer, typed comment anchors, immutable approval history, stale bases,
binary locks, release evidence links, and rollback proposal/execution.
