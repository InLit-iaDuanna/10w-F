# 万象场景库 · 原创可复用资产

v5 包含 **36 套场景、52 件建筑与物件、14 个角色**。原始暖陶村落、林间营地、荒原驿站保留；其余主题补充人物、结构分件、家具、设施与环境细节。文件是实际生成的自包含 GLB 和 Blender 渲染预览，CC0 授权。

## 骨骼与动画

14 个独立角色已有真实骨骼、归一化蒙皮和四段 GLB 动画：Idle（2秒）、Walk（1秒）、Run（约0.667秒）、Wave（2秒）。16 根骨骼按 Root、Hips、Spine、Head 及左右 UpperArm/Forearm/Hand/Thigh/Shin/Foot 命名。原地动作不带根运动；运行时角色位移由游戏控制器处理。机器人和体素角色的硬质四肢在关节处分件并采用刚性权重，衣物四肢采用线性蒙皮。

同体型角色共用 `skeleton_id: sceneops-humanoid-v1` 和 `animation_set_id: sceneops-basic-locomotion-v1`。`revisions/v5/blend/shared-humanoid-v1.blend` 是没有人物网格的共用骨架与动作模板；`revisions/v5/glb/shared-motions-v1.glb` 是没有网格的四段动作包；`revisions/v5/shared-rig.json` 记录骨骼层级、静止矩阵及用法。资产详情提供两者下载。

运行时可以把动作包中的任意 clip 直接传给目标角色的 `AnimationMixer.clipAction(clip)`。已使用独立动作包驱动全部 14 个角色，检查层级、静止变换一致性、归一化权重及实际顶点运动，无需重定向。项目整包安装只复制一份共用动作包，各角色索引引用同一路径。

模型与预览位于 `revisions/v5/`，同目录 `blend/` 包含可编辑的原生骨骼与动作文件。内置 3D 预览可选动画、暂停／继续；切离工作区或隐藏页面会停止动画循环。库中的完整场景仍保留静态布景人物，可用这些独立绑定角色替换。

新增黏土旅人、搪瓷机器人、手塑蘑菇和搪瓷落地灯；都有真实模型、材质和生成提示词。

## 可复用角色与物件

角色：原始四种配色旅人，以及医护人员、维修工程师、餐厅厨师、装甲守卫、背包探险家、舱外宇航员、服务机器人、体素冒险者。职业装备改变轮廓；职业角色不再只是换色。

新复用部件：沿街商铺、花卉种植箱、电力设施杆、医疗推车、双人餐桌椅、展品柜、金属栏杆、法兰阀门管、自动售货机、行李箱、体素树、金属水泵和维修工作台。场景详情中的部件按钮可跳转到独立资产；`reusable_asset_ids` 记录组成关系。

14 个角色各有独立二维像素图集：32×48 像素／帧，4 列步行帧 × 4 行方向（下、左、右、上），6 FPS，透明背景；脚点为 (16,46)。PNG 与 `sprite_layout` 一起使用，整数倍最近邻放大。整包安装同时复制图集和生成指南，并将资源 URL 改为项目内的静态路径。

## 风格与生成提示词

[AGENT_GUIDE.md](AGENT_GUIDE.md) 给出八种风格规范与交付要求。`agent-prompts.json` 提供每项资产 × 八种风格的完整提示词；包括目标造型、材质、尺寸、原点、可复用部件、出生点及验证要求。内置库详情中也可以选择目标风格并复制。

- 低多边形：场景库主体，实际 GLB。
- 体素：独立人物、树和村落，实际 GLB。
- 像素：实际二维角色方向／步行 PNG 图集。
- 纸艺：折面与薄片构造方向的实际 GLB 场景示例。
- 写实：提供生成规范和 PBR 材质工坊示例，尚不是完整的写实人物与环境套装。
- 手绘：提供生成规范，尚未交付独立手绘贴图套装。
- 黏土：圆润哑光人物与蘑菇，角色已绑定。
- 搪瓷：涂层金属机器人与落地灯，角色已绑定。

## 重建与核验

Blender 5.1 按顺序运行 `source/generate.py` → `source/expand.py` → `source/expand_v3.py` → `source/detail_collection.py`。前三步重建旧版本，仅在需要从零重建时运行。日常重建详细资产只运行最后一步；可加 `-- --only world-cyber,person-engineer` 选择条目。

在详细资产基础上，用 Blender 运行 `source/rig_collection.py` 生成 v5 绑定角色，然后运行 `source/export_shared_rig.py` 导出共用模板和动作包。再运行 `node source/verify_rig.mjs` 检查网页加载器中的骨骼、权重归一化和四段实际变形；`source/preview_rig.py` 渲染动作姿态。

然后使用装有 Pillow 的 Python 运行 `source/attach_guidance.py` 生成图集和指南，最后使用 Blender 运行 `source/verify.py`，并执行模块后端测试。`verification.json` 记录实际 GLB 重新导入的尺寸、三角面数、对象身份和出生点检查。

v4 模型和预览位于运行时资源目录的 `revisions/v4/`；旧版本路径保留，条目版本为 4。后续正式发布应创建新的版本目录，不覆盖已发布文件。

## Limitations

独立角色有基础骨骼动画，但没有面部、手指、IK 控制器或自动步幅匹配；目前属于适用于分件风格角色的基础动作。整景内布景人物仍为静态。像素步行帧为独立二维资产。所有场景需要由游戏项目补充玩法、碰撞体和导航。PBR 示例是程序建模与材质演示，没有照片扫描或高精度写实人物；像素图集也不是完整的二维游戏场景套装。
