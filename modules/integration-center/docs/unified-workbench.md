# 统一应用编辑器

公开入口 `loadIntegratedWorkbench()` 返回接受 `@sceneops/core-ui.IntegratedWorkbenchProps` 的懒加载 React 编辑器。宿主负责项目空态、文档读取/保存、手动样例导入、AI 模型和建议、停靠布局。

复用当前项目的健康、Worker、日志、证据与诊断面板，使用明确注入的项目transport；不在页面生成示例项目。支持集成地址、版本、能力要求与排障笔记草稿。配置不是连接证据，不从配置推断健康，也不自动探测用户填写的服务地址。

默认空项目不选择或运行 Demo。草稿通过 `onSave` 保存到当前项目的模块文档，错误可见且保留输入；`onDirtyChange` 支持切换项目提醒。旧独立入口保持兼容。

## 验证边界

本轮编辑器代理仅实现与静态阅读，未启动服务、运行测试、执行案例、构建、渲染或真实 AI。唯一启动/导入/空态烟测由主集成任务执行，结果见根交付记录；完整类型、业务流程与外部链路均未在此声明通过。
