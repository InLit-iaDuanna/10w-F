# 首次进入：本地 AI 环境配置

首次打开统一工作台时显示「选择工具 → 安装环境 → 登录与连接」。可以选择 CodeBuddy CLI、Codex CLI 或同时安装；右上角「环境配置」及 AI 设置中的同名入口可重新打开。跳过或完成仅在当前浏览器保存引导状态，不代表账号可用。

## 使用方式

1. 选择工具，继续查看当前电脑的实际安装与兼容状态。
2. 点击「一键安装所选工具」。已兼容的安装会被复用；缺少或不兼容的工具安装到 `~/.local/share/sceneops/cli`。安装状态按工具显示，关闭向导后安装继续，重新打开可以查看。
3. macOS 点击「打开终端登录」，在官方交互流程中完成授权。其他系统按页面的终端命令和官方文档操作。
4. 点击「我已登录，检查连接」。这会使用现有 provider/check 发送一次最小真实模型请求，可能计入提供方额度。打开登录窗口、安装成功和读取版本都不视为登录成功。
5. 选择已验证的默认工具，点击「完成配置，开始使用」。仅保存该工具及实际验证的模型；首次切换工具使用 `cli-default`。原流式、执行时限及兼容服务密钥保持现有保存语义。

支持 macOS/Linux 的无管理员权限 npm 安装。当前工作台适配安装版本为 `@openai/codex@0.144.1`、`@tencent-ai/codebuddy-code@2.146.0`。Codex 执行适配器要求 0.144.1；已有其他版本保留在原位置，修复后 SceneOps 优先使用独立目录中的版本。其他终端的 PATH 和 CLI 登录凭据不被向导重写。

参考：[Codex 官方安装与登录](https://learn.chatgpt.com/docs/codex/cli)、[CodeBuddy 官方快速入门](https://www.codebuddy.cn/docs/cli/quickstart)、[Node.js 下载](https://nodejs.org/en/download)。固定版本来自当前项目适配边界，不代表官方最新版本。

## 公共接口

前端公开 `EnvironmentSetup({ autoOpen?, onOpenChange? })`。Shell 组合首次入口，并在配置向导打开时暂停边缘工具引导，避免两种引导同时争夺焦点。服务端状态归 TanStack Query；网络类型从 Pydantic/OpenAPI 生成，复用 api-client。

`create_ai_router` 组合以下端点：

| 接口 | 行为 |
| --- | --- |
| `GET /api/ai/setup` | 读取平台、npm、两个工具的安装/版本/兼容状态、登录命令及当前安装状态；未知版本保持 null。原生 Codex 无 npm 元数据时执行有界 `--version`。 |
| `POST /api/ai/setup/install` | `{providers: ['codebuddycli', 'codexcli']}`，仅接受固定提供方。异步逐项安装、单个安装最长 300 秒；返回状态，拒绝并发安装。 |
| `POST /api/ai/setup/login` | `{provider: 'codexcli'}`，在 macOS 打开固定登录命令，响应仅说明已打开终端。 |

安装/登录端点要求回环来源和配置的本地 Origin，同时保留主应用的本地令牌与 JSON 校验。不接受自定义可执行命令、包名、安装目录或自由 shell 参数；错误不返回进程输出和凭据。适配器公开 `CLISetup` / `SetupFailure`，共享 CLI 解析器让普通对话和 Agent 执行使用相同工具。

## 验证

已运行最小模拟安装 smoke、不兼容 Codex 修复 smoke 和一条前端主路径：初始零安装/登录/模型请求 → 明确安装 → 登录打开后仍未验证 → 连接失败 → 重试成功 → 保存实际验证的模型 → 重新打开引导。浏览器目视核对首次页面和步骤切换。

额外失败输出、并发、登录参数、路径优先级及本地访问约束测试已维护，未执行完整套件。验证未进行真实 CLI 安装、账号授权或模型请求。

## Limitations

- macOS 用户可双击应用根目录的 `启动 SceneOps.command`，由外层启动器一次准备 Python 和项目运行依赖、启动 Web/API 并打开页面；本向导只负责页面内的 AI CLI 安装、登录和连接验证。
- 缺少 Node.js/npm 时先从官方页面安装并重新双击启动入口；该向导不安装 Node、Blender 或 Unity。
- Windows 提供固定版本 npm 命令和官方指南；自动安装及自动打开登录终端尚未实现。
- 后端进程重启会结束在途安装并重置操作状态，已有文件在下次打开时重新检测；失败可手动重试。
- 登录授权由用户在官方流程中完成；连接验证不保证后续账号额度或模型访问一直可用。

## 后台安装时的步骤导航修复

后台安装仅限制正在安装的工具和重复安装操作，不再全局禁用「继续」「上一步」。其他已就绪的工具可继续登录、验证与保存，所有步骤均显示后台安装状态。补充模拟 Codex 安装中、CodeBuddy 已就绪的回归验证，并检查同一工具安装时登录仍不可用。
