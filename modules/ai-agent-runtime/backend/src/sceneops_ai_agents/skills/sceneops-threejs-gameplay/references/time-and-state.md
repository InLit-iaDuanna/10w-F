# 时间与状态

确定时间单位和更新归属，使用项目已有模拟时间。冷却究竟在触发、动作结束还是接触时开始，由当前设计决定；不要把持续按住与单次按下混为一谈。

添加冷却时保留原冲刺速度、持续时间、方向和移动输入。检查可用 → 触发 → 冷却 → 再次可用的状态迁移，覆盖连续按键、冷却边界与重开；暂停时是否消耗冷却沿用当前设计，不让墙钟计时悄悄改变语义。

对象组件式在拥有该行为的组件更新；ECS 在既有组件字段和对应系统内更新，查询必须包含新状态，不引入平行对象循环。HUD 读取同一份 remaining/ready 状态。

区分模拟与表现时间：暂停模拟和截图冻结不同于一般运行，不能用冻结场景证明输入或帧率。只有任务涉及手感时才调整加速度、相机跟随或事件反馈；反馈不阻挡主输入，不自动增加闪光、抖动和音频。

复用现有随机来源；若需要复现，明确时间推进、输入顺序和重置内容，避免装饰性随机改变玩法事件。固定随机种子本身不能证明完整确定性。
