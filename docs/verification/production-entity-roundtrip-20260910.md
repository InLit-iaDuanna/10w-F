## 实现说明

- 资产库扩展几何源和材质文档引用，沿用已有不可变资产版本；项目工程数据库增加最小实体记录，包含稳定部件、材质接口、采用历史与构建关联。没有新建独立对象数据库、哈希或全项目快照系统。
- 实体提供包含项目、工作区、类型、ID、版本及可选部件的对象引用；通过原命令/编辑器体系打开专业工具。规整提案、执行规整、读取实体和采用版本均有公开 API，前端类型从后端合同生成。
- 敌人适配仅位于 test123：启动时加载采用版本，波次共享几何，每只敌人复制可变材质，所有外观节点保留命中所需的敌人引用。受击恢复原材质的发光参数；销毁不释放共享几何。
- 材质按稳定对象、原始材质槽身份承接；缺失对象和槽返回具体目标。普通 PBR 已写入 GLB，不生成多余 Shader 程序。门模型和场景实例仍走原接口。
- 源码先在隔离候选中修改并构建，逐文件检查差异后更新原工程。原文件备份与差异在 `.local/entity-refinement/`。
