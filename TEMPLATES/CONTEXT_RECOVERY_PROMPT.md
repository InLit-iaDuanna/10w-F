# SceneOps Forge — Context Recovery

The previous coding conversation became too long, lost context, or ended unexpectedly.

Do not infer progress from chat memory. Reconstruct it from the repository:

1. Read governing docs and nearest module guidance.
2. Inspect Git status, recent commits, worktrees, branches, and uncommitted changes.
3. Read STATUS.md, EXECUTION_PLAN.md, handoff files, ADRs, and failing logs.
4. Run the smallest commands needed to verify the current state.
5. Produce a short recovery summary:
   - what is definitely complete;
   - what is partially complete;
   - what is broken;
   - what is unverified;
   - current ownership;
   - next minimal action.
6. Continue the assigned task only after the state is verified.

Never overwrite or discard unknown work. Never claim a feature complete based only on a prior summary.
