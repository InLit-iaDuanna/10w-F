# SceneOps Documentation Sync

1. Diff public code changes.
2. Identify affected root and module docs.
3. Update exact paths, commands, schemas, examples, status, and limitations.
4. Regenerate API/client/schema docs where supported.
5. Verify all referenced files and commands exist.
6. Keep Live/Mock/Cached claims accurate.
7. Add migration or troubleshooting notes for behavior changes.
8. Run docs link/code-block validation where available.

Never document a planned capability as implemented.
